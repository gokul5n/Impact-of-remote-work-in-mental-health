# Impact of Remote Work on Mental Life - Excel Dashboard

This project presents an Excel-based interactive dashboard that analyzes how remote work has affected mental health, work-life balance, and stress levels across various demographics and industries.

## 📊 Project Overview

The dashboard provides insights into:
- Access to mental health resources
- Work-life balance by industry and region
- Stress levels by working type
- Social isolation and demographic breakdowns

## 🛠 Tools & Techniques Used

- **Microsoft Excel**
  - Power Query for data cleaning and transformation
  - Pivot Tables for summarizing key metrics
  - Charts and Conditional Formatting for data visualization
  - Slicers for dynamic filtering by Gender, Region, and Experience Level

## ⚙️ Process Workflow

1. **Data Collection** – Imported raw employee survey data
2. **Data Cleaning** – Used Power Query to remove inconsistencies and shape data
3. **Data Analysis** – Created Pivot Tables to aggregate key metrics
4. **Visualization** – Designed charts and slicers for interactive and clean reporting

## 📌 Key Highlights

- Total records analyzed: 3,758
- Average employee age: 41
- Avg. work experience: 17.8 years
- Unified report view covering mental health, stress, isolation, and work-life balance
